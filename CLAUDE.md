# sf-ld-research – Projektkontext für Claude Code

Research-Repository zur Shakes & Fidget Legendary-Dungeon-API (`IADungeonInteract`). Kein produktiver Code, sondern Untersuchung/Dokumentation der API-Mechanik.

## Charakter des Repos
- Forschungs-/Notizsammlung, keine deploybare Anwendung
- Dient als Grundlage für mögliche spätere Projekte (z.B. Integration in sfguildsv2, sf-api-Erweiterungen oder eigenständige Tools rund um Legendary Dungeons)

## Konvention
- Da es sich um Reverse-Engineering/Research zu einem Spiel-API handelt: Erkenntnisse sauber dokumentieren (Request/Response-Beispiele, Beobachtungen, offene Fragen), damit sie später in ein konkretes Projekt überführt werden können
- Keine Zugangsdaten oder Session-Tokens aus echten Spielaccounts jemals committen – bei Beispiel-Payloads immer auf anonymisierte/platzhalter Werte achten
